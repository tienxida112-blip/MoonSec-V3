# Samples

Stored obfuscated Lua/Luau samples:

- `obfuscated/001.lua` through `100.lua` - generated outputs.
- `index.json` - sample IDs, file paths, sizes, and seeds.

Samples `001` through `007` came from the Lua tests in `Tests/`. The other samples came from algorithmic inputs that are not included here.

These files are stored outputs, not regenerated by `npm test`. To obfuscate an input you have, use:

```sh
node bin/moonsec.js input.lua -o output.lua
```
