# Samples

- `obfuscated/001.lua` through `007.lua` were regenerated with version 3.1.0, using the `moonsec-v3/plain` wire-format profile, from the retained files in `Tests/`. All seven were executed in standalone Luau. `index.json` records each source, size, seed, and profile.
- `obfuscated/008.lua` through `100.lua` are legacy stored outputs. Their original algorithmic inputs are not included, so they have not been regenerated or revalidated with this revision. The index marks them as `legacy`.

The corpus from terrorlua is not bundled here. These are this project's outputs, not genuine MoonSec reference files.

Samples are not automatically regenerated by `npm test`. To obfuscate an input you have:

```sh
node bin/moonsec.js input.lua -o output.lua
```
